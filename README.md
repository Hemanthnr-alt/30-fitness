## ⚡ Overview

This repository hosts the official landing page and distribution hub for **LockIn Fitness**, the offline-first progressive workout suite for Android.

### 🌟 Landing Page Features:
- 🌌 **Ambient Canvas Starfield:** GPU-accelerated interactive starfield background.
- 📱 **Plan Explorer:** Interactive view of progressive workout programs, exercises, and routines.
- 📥 **Direct APK Download:** Fast access to the production Android release.
- ❓ **FAQ & Architecture Guide:** Highlights the 100% offline-first SQLite philosophy.

---

## 🛠️ Stack & Architecture

- **Markup & Styling:** Semantic HTML5, responsive CSS3 with glassmorphic styling and ambient lighting.
- **Interactivity:** Vanilla JavaScript with scroll progress tracking, mobile drawer navigation, and canvas particle physics.

---

## 💻 Local Testing

Open `index.html` directly in any modern browser, or run with Python's local server:

```bash
python -m http.server 3000
```
Then visit `http://localhost:3000`.
